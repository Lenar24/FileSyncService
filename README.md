# FileSyncService

## Сервис синхронизации файлов с облачным хранилищем

Сервис для автоматической синхронизации файлов между локальной папкой 
на компьютере и облачным хранилищем Yandex.Disk.

---

## 📋 Функциональность

- **Связывание папок**: привязка локальной папки к папке в облачном хранилище
- **Отслеживание изменений**: автоматическое обнаружение новых, изменённых и удалённых файлов
- **Полная синхронизация при запуске**: содержимое облачной папки приводится в соответствие с локальной
- **Непрерывная работа**: синхронизация происходит с заданным интервалом
- **Устойчивость к ошибкам**: ошибки не прерывают работу программы
- **Логирование**: все действия записываются в файл лога

---

## 🛠️ Технологии

- **Python 3.8+**
- **Requests** — для работы с API Яндекс.Диска

## ⚙️ Установка и настройка

### 1. Клонирование репозитория

```
git clone https://github.com/Lenar24/FileSyncService.git
cd FileSyncService
```

### 2. Создание виртуального окружения

```
python -m venv .venv
source .venv/bin/activate  # Linux/Mac
# или
.venv\Scripts\activate     # Windows
```

### 3. Установка зависимостей

```
pip install -r requirements.txt
```

### 4. Настройка конфигурации

```
Скопируйте файл примера конфигурации и заполните его:
cp config.ini.example config.ini

Откройте config.ini и укажите свои параметры:
[Settings]
sync_folder = /home/username/Documents/SyncFolder   # Путь к локальной папке
cloud_folder_name = CloudBackup                     # Имя папки в облаке
yandex_token = YOUR_YANDEX_TOKEN_HERE               # Токен Яндекс.Диска
sync_interval = 60                                  # Интервал синхронизации (сек)
log_file = sync_service.log                         # Файл лога
```

### 5. Получение токена Яндекс.Диска

```
1. Перейдите на страницу создания приложений
2. Создайте приложение с правами:
 * cloud_api:disk.info
 * cloud_api:disk.read
 * cloud_api:disk.write
 * cloud_api:disk.app_folder
3. Получите OAuth-токен по инструкции в документации Яндекс.Диска
```

## 🚀 Запуск

```
python main.py
Сервис запустится, выполнит сначала полную синхронизацию и будет работать 
в фоновом режиме с заданным интервалом 60 секунд.

Для остановки сервиса нажмите Ctrl+C
```

## 🔧 Устранение неполадок

**Ошибка "Неверный токен доступа"**
* Проверьте правильность токена в config.ini
* Убедитесь, что у приложения есть все необходимые права

**Ошибка "Синхронизируемая папка не существует"**
* Проверьте путь в config.ini
* Создайте папку вручную: mkdir -p /path/to/folder

**Файлы не синхронизируются**
* Проверьте интернет-соединение
* Посмотрите файл лога на наличие ошибок
* Убедитесь, что сервис запущен и работает
